# Track B Guarded PAPER Roster Authority

`config/track_b_guarded_paper_roster.json` is the source-controlled default
fallback guarded PAPER roster. It is authority-bearing only when the runtime is
not launched with an explicit profile-scoped roster path.

Approved paper-stack starts should prefer explicit profiles generated by
`scripts/track_b_start_paper_stack.sh`. The wrapper writes a scoped roster under
the runtime output directory and exports `TRACK_B_GUARDED_PAPER_ROSTER_PATH` so
the running process consumes that profile-specific authority instead of the
fallback config.

Roster JSON used as authority must include:

- `schema_version = track_b_guarded_paper_roster_v1`
- `paper_account_id = DUM882026`
- `live_money_eligible = false`
- `paper_proof_invoked = false`
- `enabled_strategy_ids`
- `disabled_strategy_ids`
- `max_quantity_per_strategy = 1`

Malformed roster files fail closed before lane enablement. Updating the fallback
roster should be committed with focused roster validation tests. Updating an
explicit active profile should happen in the start-wrapper profile generator and
its focused script tests.
