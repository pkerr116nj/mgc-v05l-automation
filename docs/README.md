# Documentation

This directory contains the repository's durable project documentation.

Start with the root `README.md` for the recommended reading order, taxonomy, dependency map, and Knowledge Foundation health summary.

## Organization

- `architecture/`: baselines, proposals, reviews, decisions, narratives, invariants, and long-term vision documents.
- `operations/`: operational baselines, policies, closeouts, and operator-environment documents.
- `research/`: durable research terminology, questions, experiments, and findings.
- `roadmap/`: current, next, and deferred planning.
- `epics/`: active multi-step product and architecture objectives.
- `specs/`: older and subsystem-specific specifications retained for reference.
- `release-candidate/`: release-candidate material retained where applicable.

Generated artifacts remain under `outputs/`, not under `docs/`.
